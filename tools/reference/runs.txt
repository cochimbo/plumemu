# The runs of the image and sound reference (see README.md).
#
# One per line:  app | name | game | frames | extra arguments
#   app     sega (plumsg-headless) or nintendo (plumnin-headless)
#   name    what the run is called in the results
#   game    a built-in test program (--test-rom...) or a path under the ROMs folder
#           that fetch.sh fills ("240p/240pSuite-1.32.bin", "gb/blargg/...")
#   frames  how many frames to run
#   extra   more plumsg-headless / plumnin-headless arguments; @SF2 is the SoundFont
#           (GeneralUser GS, which fetch.sh downloads), @DIR the ROMs folder
#
# Each run writes the hash of its last frame, of its whole sound and of the log with
# one picture and sound hash per frame. A change in any of them shows up in the diff.
